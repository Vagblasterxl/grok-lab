# GROK LAB

One-page playground that folds 19 mini-app briefs into a single teaching studio.

**Thesis:** turn a knob, watch hidden structure appear.

## Live
- GitHub: https://github.com/Vagblasterxl/grok-lab
- Netlify: http://grok-lab.netlify.app
- Linear: https://linear.app/keneticnrg/issue/KEN-9

## What is combined

### Shell (event + SaaS + portfolio primitives)
Sticky nav, hero, countdown to Session 01, agenda, concept/speaker cards, ticket tiers, RSVP + success, venue placeholder, testimonials, email signup, filter chips, footer.

### Labs
| Lab | Briefs folded |
| --- | --- |
| Chance | Probability dice/coin, trials, live histogram vs theory |
| Primes | Animated sieve, click factors |
| Infinity | Mandelbrot zoom/pan + fractal tree |
| Life | Conway paint, play/pause, presets |
| Waves | Fourier epicycles + theremin + 16-step + visualizer |
| Matter | 2D physics drop/stack/drag |
| Symmetry | Kaleidoscope |
| Desk | Live poll + kanban + budget (localStorage `groklab.*`) |

### Next session
3D terrain flyer, vector-field plotter.

## Run
Open `index.html` or deploy the repo as a static site. No build step.
